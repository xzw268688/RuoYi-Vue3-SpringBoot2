  ## 项目简介

  RuoYi-Vue 是一个基于 Spring Boot + Vue 的前后端分离权限管理系统，包含用户管理、角色管理、菜单管理、部门管理等功能。

  ## 技术栈

  **后端：**
  - Spring Boot 2.x
  - MyBatis
  - MySQL
  - Redis
  - Spring Security

  **前端：**
  - Vue 2
  - Element UI
  - Axios
